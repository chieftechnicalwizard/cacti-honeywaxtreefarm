# Honey Wax Tree Farm — Cactus Sanctuary (`cacti.honeywaxtreefarm.com`)

24/7 live *Trichocereus* cactus conservatory broadcast studio & deep-researched botanical lineage archive for [Honey Wax Tree Farm](https://www.honeywaxtreefarm.com).

## Contents
- `index.html` — Standalone responsive portal (works both directly via GitHub Pages / `cacti.honeywaxtreefarm.com` and inside Google Sites Full-Page Embed):
  - Embedded 4-camera 24/7 YouTube Live switcher + 2×2 Quad Live Wall + 13-video *Cactus Cam* playlist
  - Complete botanical provenance dossier for all **17 Trichocereus seedling crosses** & **23 named parent clones**
  - Interactive labeling checklist, search, trait filters, CSV export, and printable `@media print` stake tags
  - Links to [Honey Wax Tree Farm](https://www.honeywaxtreefarm.com), [Shekinah Shine](https://www.shekinahshine.org/), [@chieftechnicalwizard](https://github.com/chieftechnicalwizard), groundskeeping donations, and botanical partners
- `assets/` — Custom ArtCraft visuals (`hwtf_crest.svg` / `hwtf_crest.png` from VectorCraft, `hero_sanctuary.webp` via PhotoCraft, and optimized camera preview plates)
- `SITE_IDEAS.md` — Multi-site architecture & expansion roadmap

## Custom Domain Setup (`cacti.honeywaxtreefarm.com`)
Add one DNS record in Squarespace Domains:
- **Type:** `CNAME` · **Host:** `cacti` · **Data:** `chieftechnicalwizard.github.io`

Then bind `cacti.honeywaxtreefarm.com` in GitHub Pages Settings (with *Enforce HTTPS* enabled).
